---
title: 测试驱动开发（TDD）
description: AI 生成代码越快，验证越该提前
---

AI 生成代码的速度远快于人，于是**验证**成了新的瓶颈。TDD 的"先写测试"恰好把验证提前：

```bash
# 红：写一个会失败的测试
npm test -- --run src/utils/slugify.test.ts

# 绿：写最少的实现让它通过
# 重构：在测试保护下改进实现
```

<Callout type="warn" title="注意">
  测试本身也可能有 bug。让 AI 同时生成"实现"和"测试"再互相验证，容易出现两边逻辑一起错的假绿。关键路径的测试要自己过一遍眼睛。
</Callout>
